# SuperSimpleFlashDrive
Designing a tiny (16 MB!) flash drive with a WCH CH552 microcontroller and a Winbond W25Q128 NOR Flash chip.
<img width="2160" height="755" alt="flashdrive_boardCAD" src="https://github.com/user-attachments/assets/ed39ef9c-f9c3-4329-97d2-b200c2a40691" />

## What is this?
I wanted to try creating a USB flash drive myself! This will give me a chance to learn a lot more about USB devices.

WCH's CH552 is a low cost microcontroller (currently about 40 cents in low quantities). It has a built-in USB peripheral, 16K of ROM, and 1K of RAM.
